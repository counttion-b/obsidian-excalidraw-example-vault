# 第12讲 牛顿运动定律 #h0
# 知识讲解

## 牛顿第一定律

### 伽利略理想斜面实验

1. 亚里士多德的观点：亚里士多德（Aristotle，公元前384～前322），古代先哲，古希腊人，世界古代史上伟大的哲学家、科学家和教育家之一，堪称希腊哲学的集大成者。他是柏拉图的学生，亚历山大的老师。

亚里士多德先生在对运动现象进行大量观察后提出，物体在水平面上的运动，需要借助外力才能维持，如果外力停止作用，物体就要静止下来。这是因为地面上的物体都跟地球一样，他们的“自然本性”是静止；而天体却与地球不同，它们的“自然本性”是以地球为中心做圆周运动。

亚里士多德认为：必须有力作用在物体上，物体才能运动，没有力的作用，物体就要静止。

![[第12讲 牛顿运动定律_files/327af32c-fd4e-442d-b2a0-b897bfeb8844.png|200]]

亚里士多德

如果仅靠自己的直观感觉来看待力与运动之间的关系，我们会觉得亚里士多德的观点似乎更符合日常经验。在亚里士多德看来：马不拉车，车就不动。这难道不是证明了有力才有运动，运动需要外力来维持吗？

![[第12讲 牛顿运动定律_files/99ffc747-1c92-47be-b31b-c01c4d408c43.png|300]]

2. 伽利略的观点：16~17世纪的意大利物理学家、天文学家。他在科学上为人类做出过巨大贡献，是近代实验科学的奠基人之一。

![[第12讲 牛顿运动定律_files/43a086f2-a238-491e-ad70-77ec38a08492.png|200]]

伽利略（1564.2.15~1642.1.8）

由于亚里士多德的理论看上去很“靠谱”，而且符合人们的日常生活经验，因此，为世人认可并广为流传。然而在探究运动原因的过程中，正是由于这个错误判断维持了近两千年，而在这漫长的岁月里，物理学的发展一直没有突破性的进展。这说明人们对于物理现象的研究还没有掌握科学的方法。直到三百多年前，伽利略才创造了有效的研究方法，揭示了现象的本质，开启了物理学的崭新一页。

到了公元17世纪，意大利科学家伽利略对亚里士多德的理论进行了深入的研究，伽利略通过实验和逻辑推理提出：物体的运动不需要力来维持，力是改变物体运动状态的原因。

为了证明自己的观点，伽利略设计了一个实验：

【实验1】两斜面对接，让静止的小球沿一个斜面滚下来，小球将滚上另一个斜面。将斜面变得越光滑，小球上升的高度就越接近下落的高度。伽利略推测：如果没有摩擦，小球将上升到原来静止时的高度。

![[第12讲 牛顿运动定律_files/a6232b13-59ae-401c-a18d-04d841033a4c.png|200]]

【实验2】如果减小第二个斜面的倾角，小球在这个斜面上仍然要达到原来的高度，但要在斜面上通过更长的距离。

![[第12讲 牛顿运动定律_files/2226da73-7b30-48a8-be9f-37519a2c4e2e.png|200]]

【实验3】继续减小第二个斜面的倾角，使它成为水平面，小球不可能达到原来的高度，就要沿水平面以不变的速度持续运动下去。

当然，我们不能消除一切阻力，也不能把实验2中的斜面做得无限长，所以伽利略的实验是一个“理想实验”。

![[第12讲 牛顿运动定律_files/b6f6a486-0d7a-407b-8d7c-5e88cfb9b5f2.png|200]]

3. 笛卡尔的观点：笛卡尔是法国著名的哲学家、物理学家、数学家、神学家。笛卡尔是二元论的代表，留下名言“我思故我在”，被黑格尔称为“现代哲学之父”。

笛卡尔也研究了这个问题，他指出：如果运动中的物体没有受到力的作用，将继续以同一速度沿着同一条直线运动，既不会停下来，也不会偏离原来的方向。他还认为，这应该成为一个原理，它是整个人类自然观的基石。

![[第12讲 牛顿运动定律_files/32dbb6a1-6e75-404d-b35d-c439dcf8738c.png|200]]

笛卡尔的靓照

4. 理想实验方法：理想实验也叫假想实验或思想实验，它是在可靠的实验基础上采用科学的抽象思维来展开的实验，是人们在思想上塑造的理想过程，它不能由实际的实验来验证。

伽利略的理想斜面实验虽然是想象中实验，但这个实验反映了一种物理思想，它是建立在可靠的事实基础之上的，以事实为依据，以抽象为指导，抓住主要因素，忽略次要因素，从而深刻地揭示了自然规律。

### 牛顿第一定律

英国科学家牛顿在伽利略、笛卡尔等前辈科学家研究的基础上，在他的明珠《自然哲学的数学原理》一书中，总结出了动力学的一条最基础的定律：一切物体总保持匀速直线运动状态或静止状态，直到外力迫使它改变运动状态为止。

这就是牛顿第一定律（Newton first law）。物体保持匀速直线运动或静止状态的特性，叫做惯性（inertia）。牛顿第一定律又叫惯性定律（law of inertia）。

牛顿第一定律是在大量事实的基础上，通过理想实验得到的，它揭示了力和运动的关系：力不是维持物体运动的原因，而是改变物体运动状态的原因。

牛顿第一定律涉及两个重要的物理概念：力和惯性。力，不仅是物理学中的基本概念，也是日常生活中用得很多的一个名词，这在前面已经讨论过了。那么惯性又是什么呢？

1. 惯性的大小：惯性是一切物体的固有属性，它时时处处伴随着我们。生活经验告诉我们，质量不同的物体保持运动状态的“本领”是不一样的。质量越大的物体，它保持原来运动状态的“本领”越大，表明它的惯性越大。所以物体的惯性是有大小的，物体的质量就是惯性大小的唯一量度。

![[第12讲 牛顿运动定律_files/668cef1e-09f8-4710-9be4-779a170666e7.png|300]]



自行车很容易刹车，以同样速度运动的火车则需滑行很长一段路才能停下
![[Pasted image 20260402152659.png|300]]

空军歼击机的质量比运输机、轰炸机的质量小得多，而且空战中还要抛掉副油箱，想想这是为什么？

2. 对惯性概念的准确理解：

（1）普遍性：一切物体都具有惯性，惯性是物体的固有属性。

（2）相关性：惯性的大小只与物体的质量有关，与其他因素（如受力情况、运动情况）无关。

（3）唯一性：质量是惯性大小的唯一量度。

3. 惯性的表现形式：

（1）在不受力条件下，惯性表现为“保持原来的运动状态”，有“惰性”的意思。

（2）在受力条件下，惯性表现为运动状态改变的难易程度，质量越大，惯性越大，对改变运动状态的“抵抗性”越大，运动状态越难以改变。

## 牛顿第二定律

### 牛顿第二定律的内容

1. 内容：物体的加速度跟物体所受的合外力成正比，跟物体的质量成反比，加速度的方向跟合外力的方向相同，公式可写为：$F=kma$．

2. 力的单位：国际单位制中，力的单位是牛顿．

“牛顿”，是根据牛顿第二定律定义的：规定使质量为$1\text{kg}$的物体获得$1\text{m/s}^2$的加速度的力为$1\text{N}$，即$1\text{N}=1\text{kg}\times1\text{m/s}^2$．

3. 比例系数$k$：根据$F=kma$，$k=\frac{F}{ma}$，$k$的单位由$F$、$m$、$a$三者的单位共同决定，当三者的单位分别为$\text{N}$、$\text{kg}$、$\text{m/s}^2$时，$k=1$．即牛顿第二定律可以写为$F=ma$．

### 牛顿第二定律的性质

1. 因果性：力是产生加速度的原因，有力就有加速度，没有力就没有加速度；

2. 同一性：$a$、$m$、$F$与同一物体某一状态相对应；

3. 矢量性：$F=ma$是一个矢量表达式，加速度的方向由合外力的方向决定；

4. 瞬时性：$F=ma$是对运动过程中每一瞬间成立的，当物体（质量一定）所受外力发生突然变化时，作为由力决定的加速度同时发生突变，牛顿第二定律是一个瞬时对应的规律；

5. 独立性：物体受多个力时，每个力各自独立地产生一个加速度，而物体的加速度则是每个力产生的加速度的矢量和．

### 力学单位制

1. 物理公式在确定物理量的数量关系的同时，也确定了物理量的单位关系．因此物理学中选定七个物理量的单位作为基本单位，根据物理公式中其他物理量和这几个物理量的关系，推导出其他物理量的单位．这些推导出来的单位叫做导出单位．基本单位和导出单位一起组成了单位制．

2. 在国际单位制（$\text{SI}$）中的基本单位有：

    （1） 力学：长度$-$米 （$\text{m}$）、质量$-$千克（$\text{kg}$）、时间$-$秒（$\text{s}$）；

    （2） 电学：电流$-$安（$\text{A}$）；

    （3） 热学：热力学温度$-$开（$\text{K}$）、物质的量$-$摩（$\text{mol}$）；

    （4） 光学：发光强度$-$坎德拉（$\text{cd}$）．

3. 其它为导出单位，如：力$-$牛顿（$\text{N}$， $\text{1N=1kg}\times \text{m/}{{\text{s}}^{2}}$）、速度$-$米每秒（$\text{m/s}$）、加速度$-$米每二次方秒（$\text{m/}{{\text{s}}^{2}}$）等．

4. 单位制：基本单位和导出单位一起组成了单位制．

### 动力学观念

从受力确定运动情况：

1. 通过对研究对象进行受力分析求出合外力，根据牛顿第二定律求出加速度；

2. 根据研究对象的运动初始条件（初位置和初速度），结合运动学公式可对运动情况进行分析、求解．

从运动情况确定受力：

1. 根据研究对象的运动情况，由运动学公式求出加速度；

2. 利用牛顿第二定律可确定研究对象所受的合外力，从而求出未知力或其相关量，如动摩擦因数、劲度系数、力的角度等．
