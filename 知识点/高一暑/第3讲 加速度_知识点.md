# 知识讲解

## 加速度

1. 加速度：

（1）定义：物体速度的变化量与发生这一变化所用时间的比值。

（2）表达式：$a$=$\frac{{{v}_{t}}-{{v}_{0}}}{Δt}$$=\frac{\Delta v}{\Delta t}$（比值定义法）。

（3）加速度的单位：在国际单位制中，加速度的单位是$\text{m/}{{\text{s}}^{2}}$或$\rm m\cdot s^{-2}$。

（4）物理意义：表示物体速度改变快慢的物理量，也可理解为速度变化率，数值上等于单位时间内速度的变化量。

2. 加速度的性质：

（1）矢量性：与$\Delta v$的方向相同，与$v$的方向没有必然联系。

（2）因果性：$\Delta v$$\propto$$a$

3. 速度的增减：

（1）若 $a$、$v$ 的方向相同，物体做加速运动。

（2）若 $a$、$v$ 的方向相反，物体做减速运动。

![[第3讲 加速度_files/b0b345a339d145cca44234c88edb919b.png|300]]

4.匀变速直线运动：加速度恒定不变的直线运动叫做匀变速直线运动。
