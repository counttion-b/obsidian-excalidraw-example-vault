## 物理中的函数

在物理学中,我们所涉及的变量总是具有物理意义的,而且它们都是可以测量的。例如分析做匀速直线运动的物体,运动的位移x与经历的时间t之间的函数关系$x = v t$

单从数学上看,v是常量,x与t是变量,t是自变量,x是因变量。x是t的单值函数。函数的,定义域是一切实数,值域也是一切实数。由于这是一个物理问题,仅作上述理解是不够的,就本题而言,应增加如下内容:v是物体运动的速,度,t是物体运动所经历的时间,x是对应时间t物体所运动的位移。该函数式给出了物体运动的位移随,时间的变化而变化的规律。

## 物理中的函数

### 复合函数

一般情况，两个变量x与y之间的函数关系,通常用函数符号f(x)表示为

$y = f ( x )$

其中f是函数符号,该式只说明了y是x的函数,其中x为自变量,但并没有具体指明x与y之间具有什么样的函数关系。若已知具体的函数关系,例如$y = x ^ { 2 }$,则可将上式记作

$y = f ( x ) = x ^ { 2 }$

在物理学中常遇到如下函数关系,y是x的函数,而x又是t的函数,即

$y = f ( x )$

$x = g ( t )$

当g(t)在f的定义域内,此时上述两式可写为

$y = f \left[ g ( t ) \right]$

这就表示,y是t的函数。这时称f[g(t)]是$y = f ( x )$与$x = g ( t )$)的复合函数,其中x称为中间变量。

如，将两函数$y = f ( \theta ) = \sin \theta$(1)、$\theta = g ( t ) = \omega t$(2)，将第(2)式代入第(1)式消去θ,可得

$y = \sin \omega t$

### 多元函数

前面是因变量y依赖于单个自变量x的函数$y = f ( x )$的有关问题，但在很多自然现象以及实际问题中,经常会遇到多个变量之间的依赖关系,现考虑多个自变量的函数。

设有变量x,y和z。如果当变量x,y在一定范围内任意取定一对值(x,y)时,变量z按照一定的法则f,

总有唯一确定的数值和这对值对应,则称这个对应法则f为x,y的二元函数。变量x,y称为自变量,变量

z称为因变量。自变量x,y的变化范围称为函数的定义域。用符号记作

$z = f ( x , y )$

与自变量x,y的一对值(x,y)对应的因变量z的值f(x,y),称为二元函数f在(x,y)处的函数值

类似地,可以定义三元函数$u = f ( x , y , z )$以及三元以上的函数。

### 矢量坐标

在空间直角坐标系中,任一矢量A沿坐标轴方向可以分解为三个分矢量 $A _ { x }$, $A _ { y }$, $A _ { z }$,

即$A = A _ { x } i + A _ { y } j + A _ { z }k$

其中, $A _ { x }$, $A _ { y }$, $A _ { z }$分别为矢量A在三个坐标轴上的分量。i、j、k为x、y、z轴的正向单位矢量,这就是矢量的坐标表示。

设两空间矢量A,B的坐标表示式为

$A = A _ { x } i + A _ { y } j + A _ { z } k$

$B = B _ { x } i + B _ { y } j + B _ { z } k$

则有

$A \pm B = ( A _ { x } \pm B _ { x } ) i + ( A _ { y } \pm B _ { y } ) j + ( A _ { z } \pm B _ { z } ) k$

### 矢量函数

位置矢量r还可用另外一些标量变量来表示。例如在直角坐标系中,设物体位置的空间坐标为xy;,那么,这时r的矢量函数记作

$r = r ( x , y , z )$

若x,y,z都是时间t的标量函数,则有

$\left\{ \begin{matrix} x = x ( t ) \\ y = y ( t ) \\ z = z ( t ) \end{matrix} \right.$

按矢量r的坐标表示式,关于t的矢量函数可写成

$r = x ( t ) i + y ( t ) j + z ( t ) k$

如，在研究平抛运动的物体的位置时,以抛出点为原点,初速度 $v _ { 0 }$的方向为x方向,竖直向下为y方向建立坐标系,请写出表示物体位置与抛出点间的距离的函数关系。

物体位置与抛出点间的距离有三种表述方式：

(1) 参数形式：$\begin{cases} x = v_0 t \\ y = \frac{1}{2} g t^2 \end{cases}$，式中参数t为物体运动的时间，g为重力加速度。

(2) 矢量形式：$r = x(t)i + y(t)j = v_0 ti + \frac{1}{2}gt^2 j$。

(3) 标量形式：$r = \sqrt{x^2 + y^2} = x \sqrt{1 + \frac{g^2}{4v_0^4} x^2}$或$\sqrt{\frac{2v_0^2}{g} y + y^2}$。

## 导数

在物理学中为了求非匀速直线运动物体在某一时刻 $t _ { 0 }$的瞬时速度,需要计算位置改变量$Δx$(即位移)与时间改变量$Δx$(之比的极限

$\lim _ { \Delta t \rightarrow 0 } \frac { \Delta x} { \Delta t } = \lim _ { \Delta t \rightarrow 0 } \frac { x ( t _ { 0 } + \Delta t ) - x ( t _ { 0 } ) } { \Delta t }$

在许多实际问题中,例如物体运动速度变化快慢程度;物体温度随时间变化速度;静电场中电势沿某一方向变化的规律等,虽然它们的具体含义各不相同,物理意义各异,但是它们的数学形式是相同的,都可以归结为研究瞬时速度这种类型的极限问题。在自然科学和工程技术领域里,还有许多其他量具有这种数学形式。我们抽掉上述各种问题的具体含义,抓住它们在数量关系的共性,就可引出函数的导数概念。

当我们研究一个函数自变量与因变量之间的关系时，除了它们数值上“静态的”对应关系外，往往还需要有“运动”或“变化”的观点，即着眼于研究函数的变化趋势、增减快慢等，这也就是函数的“变化率”的概念。

当函数$y=f\left(x\right)$的自变量$x$从$x_0$增加一个增量$\Delta x$，即从$x_0$变为$x_0+\Delta x$，那么对应的函数值也从$f\left(x_0\right)$变到$f\left(x_0+\Delta x\right)$，于是因变量$y$的增量：

$\Delta y=f\left(x_0+\Delta x\right)-f\left(x_0\right)$

那么，$\Delta y$与$\Delta x$的增量比写作：

$\frac{\Delta y}{\Delta x}=\frac{f\left(x_0+\Delta x\right)-f\left(x_0\right)}{\Delta x}$

这个比值，就是函数在区间$\left[x_0,x_0+\Delta x\right]$内的平均变化率。当$\Delta x\rightarrow0$时，上述变化量比的极限就是函数在$x_0$处的瞬时变化率，数学上称其为$y=f\left(x\right)$在$x_0$处对$x$的导数，记作$y'\left(x_0\right)$或者$f'\left(x_0\right)$，即

$y'\left(x_0\right)=f'\left(x_0\right)=\lim_{\Delta x\rightarrow0}\frac{\Delta y}{\Delta x}=\lim_{\Delta x\rightarrow0}\frac{f\left(x_0+\Delta x\right)-f\left(x_0\right)}{\Delta x}$

当然，除了$y'\left(x_0\right)$、$f'\left(x_0\right)$外，导数还常常写成$\frac{\text{d}y}{\text{d}x}$、$\frac{\text{d}f}{\text{d}x}$、$\frac{\text{d}}{\text{d}x}f\left( x\right)$，注意这里的$\dfrac{\text{d}}{\text{d}x}$代表的是求导的运算符号，是一个整体，不能拆开，不要与微分搞混。另外需要指出的是，函数$f\left(x\right)$的导数$f'\left(x\right)$本身也是关于$x$的一个函数，不同的$x$值对应的$f'\left(x\right)$也不同。

设函数$y = f ( x )$在点 $x _ { 0 }$的某一邻域内有定义,当自变量x在 $x _ { 0 }$处有增量$\Delta x$,点$x _ { 0 } + \Delta x$仍在该邻域内)时,相应地函数有增量$\Delta y = f ( x _ { 0 } + \Delta x ) - f ( x _ { 0 } )$,如果$\Delta y$与$\Delta x$之比当$\Delta x$→0时的极限存在,则称这个极限值为$y = f ( x )$在点$x _ { 0 }$B处的导数,记作为$f ^ { \prime } (x_{0})$,即

$f ^ { \prime } ( x _ { 0 } ) = \lim _ { \Delta x \rightarrow 0 } \frac { \Delta y } { \Delta x } = \lim _ { \Delta x \rightarrow 0 } \frac { f ( x _ { 0 } + \Delta x ) - f ( x _ { 0 } ) } { \Delta x }$

也可记作

$y ^ { \prime } | x = x _ { 0 }$,$\frac { d y } { d x } | x = x _ { 0 }$或$\frac { d f ( x ) } { d x } | x = x _ { 0 }$

## 导数的几何含义

这里我们将从函数图像上来帮助大家理解导数对应函数的“变化率”这一概念。如图所示为某一函数的图像，我们在函数图像上任取一点$A\left(x_0,y_0\right)$，当自变量$x$有一增量$\Delta x$时，函数值$y=f\left(x\right)$也会相应增加$\Delta y$，此时对应于函数图像上的另一点$B\left(x_0+\Delta x,y_0+\Delta y\right)$，此时$\Delta y$与$\Delta x$的增量比即为直线$AB$的斜率。当$\Delta x$逐渐减小时，$\Delta y$也会相应减小，此时$B$点会沿着函数图像向$A$点靠近。当$\Delta x\rightarrow0$时，直线$AB$会变成函数图像在$A$点的切线，此时$y=f\left(x\right)$在$A$点切线的斜率$k$就等于函数在$A$点的导数，即：

$k=\lim_{\Delta x\rightarrow0}\frac{\Delta y}{\Delta x}=\lim_{\Delta x\rightarrow0}\frac{f\left( x_{0}+\Delta x\right)-f\left( x_{0}\right)}{\Delta x}=f'(x_{0})=\left. \frac{\text{d}y}{\text{d}x}\right|_{x=x_{0}}$

![[05-物理中的函数和导数_files/5bc1f28a-23a6-4f3e-af31-7e91f8654c92.jpg|300]]

这里需要指出的是，直线的斜率$k$有正有负，那么一个函数的导数也有正有负。当函数图像上某一点$A\left(x_0,y_0\right)$的切线斜率$k>0$时，函数在此点的导数$f'\left(x_0\right)>0$，说明函数值在$A$点附近正在递增。同理当函数图像上一点$A\left(x_0,y_0\right)$的切线斜率$k \lt 0$，说明函数值在$A$点附近正在递减。

## 导数的物理意义

瞬时速度的导数表示为 $v=\lim _{\Delta t \rightarrow 0} \frac{\Delta x}{\Delta t}=\frac{\mathrm{d} x}{\mathrm{~d} t}$;

## 基本初等函数的导数

基本初等函数有常值函数、幂函数、指数函数、对数函数、三角函数、反三角函数6种，基本函数的导数只能通过导数的定义（和反函数的性质）来求解，下面我们介绍高中阶段常见的前5种基本初等函数和它们的导数。

（1）常值函数

常值函数（也称常函数）是指函数值不发生改变（即是常数）的函数。常函数常以$f(x)=const$或$f(x)=C$表示。如$f(x)=8.18$。

由于常函数$f(x)=C$的值不随自变量$x$变化而变化，所以常函数的导数$f'\left(x\right)=0$

（2）幂函数

幂函数是指以底数为自变量，幂为因变量，指数为常数的函数。幂函数常以$f(x)=x^n$表示，这里的指数$n$可以是任何有理数。

幂函数的导数$f'\left(x\right)=nx^{n-1}$。

（3）指数函数

指数函数是指以指数为自变量，幂为因变量，底数为常数的函数。指数函数以$f(x)=a^x$表示，式中$a>0$且$a\neq 1$。

指数函数的导数$f'\left(x\right)=a^x \ln a$。特别地，当底数$a$是自然常数$e$（即$a=e$）时，$f'\left(x\right)=e^x$，即$f(x)=e^x$的导数还是原函数本身。

（4）对数函数
对数函数是指以幂为自变量，指数为因变量，底数为常数的函数。对数函数以$f(x)=\log_a x$表示，式中$a>0$且$a\neq 1$。
对数函数的导数$f'\left(x\right)=\frac{1}{x\ln a}$。特别地，当底数$a$是自然常数$e$（即$a=e$）时，$f'\left(x\right)=\frac{1}{x}$。

（5）三角函数
三角函数是指以角度为自变量，角度对应任意两边的比值为因变量的函数。
在这里我们给出两个三角函数的导数，其余三角函数的导数可以通过后面我们介绍的求导法则来求解。正弦函数$f(x)=\sin x$的导数$f'\left(x\right)=\cos x$，余弦函数$f(x)=\cos x$的导数$f'\left(x\right)=-\sin x$。

## 导数的四则运算法则

设$f$和$g$都是可导函数，$\alpha$和$\beta$都是常数，那么

$\left( \alpha f\pm\beta g\right)'=\alpha f'\pm\beta g'$

$\left(fg\right)'=f'g+fg'$

若对于定义域内的$x$都满足$g\left(x\right)\ne0$，那么

$\left(\frac{f}{g}\right)'=\frac{f'g-fg'}{g^2}$

## 应用：求物理量的变化率

一般来说，物理量都是随时间的变化量，会随着时间的推移而发生改变。对于物理量$A$来说，$\frac{\Delta A}{\Delta t}$计算的是一段时间内该物理量的平均变化率。而当$\Delta t\rightarrow0$时，就是对变化率取极限，对应的是瞬时变化率，即

$\lim_{\Delta t \to 0}\frac{\Delta A}{\Delta t}=\frac{{\rm d} A}{{\rm d} t}$

我们在高中物理中最早接触到的物理量就是物体的运动速度。物体运动的平均速度是由物体位移随时间的平均变化率$v=\frac{\Delta x}{\Delta t}$确定，而物体运动的瞬时速度是由物体通过位移随时间的瞬时变化率$v=\lim_{\Delta t \to 0}\frac{\Delta x}{\Delta t}=\frac{\text{d}x}{\text{d}t}$确定。在之前，我们只能得到几种特殊运动模式中物体的瞬时速度随时间变化关系，而不能通过物体位置随时间的变化规律得到一般的瞬时速度表达式。求导提供给我们的，是对于任意给定的运动，求出其速度的数学方法，这种方法是更通用也是更本质的。

不仅在运动学中，在物理学的其他方面，时间都是非常特殊的一个维度，我们将会接触到的许多物理量都与其他物理量的变化率有关。因此，物理学家将物理量对时间的导数与对其他自变量的导数区分开来，单独给它们一个符号，即通过给字母上方加点的方式来表示对时间的导数。对于物体的坐标$x$，$\overset{\centerdot }{x}$和$\overset{\centerdot \centerdot }{x}$分别代表$x$对时间的一阶导数和二阶导数，我们知道它们代表的物理含义就是物体的速度和加速度。

## 应用：求函数的极值

函数的导数刻画了函数的瞬时变化率，从而很好地描述了函数局部变化的性质。我们在导数的几何意义中已经提到了导数与函数单调性的关系。对于在开区间内的可导函数，如果它的导数大于零，则说明函数正在单调递增。同理，如果导数小于零，则说明函数正在单调递减。作为一个连续函数，随着$x$的递增，往往会遇到函数值$y=f(x)$有时递增有时递减的情况。如图所示，不难看出，当函数达到极大值、极小值或拐点时，有

$f'(x_0)=0$.

需要注意的是，导数为零是取极值的必要条件，并不是充分条件。例如，函数$y=x^3$在$x=0$处虽然导数为零，但并不是极值点。结合之前提到过的单调性判据，我们可以得到可导函数取极值的充要条件：

在$x>x_0$的小邻域内，$f^{'}(x)$大于（小于）零，且在$x<x_0$的小邻域内，$f^{'}(x)$小于（大于）零，则$x=x_0$为函数$f(x)$的极小（大）值点。

而对于二阶可导的函数，还有一条更简洁的充要条件：

对于二阶可导的函数$f(x)$，如果它在$x=x_0$处的导数为零，且二阶导大于（小于）零，则$x=x_0$为函数的极小（大）值点。
