# 机械能守恒列式
1．初状态的动能、势能之和等于末状态的动能、势能之和：$E_{\mathrm{k} 1}+E_{\mathrm{p} 1}=E_{\mathrm{k} 2}+E_{\mathrm{p} 2}$（要选零势能参考平面）；

2．动能的增加量（减少量）等于势能的减少量（增加量）：$\Delta E_{\mathrm{k}}=-\Delta E_{\mathrm{p}}$（不用选零势能参考平面）；

3．$A$ 物体机械能的增加量（减少量）等于 $B$ 物体机械能的减少量（增加量）：$\Delta E_A=-\Delta E_B$（不用选零势能参考平面）。
# 机械能守恒计算
关于机械能守恒计算的解题方法：

1．初末状态法：用初末状态机械能相等列式时，要注意选取合适的零势能面，一般选取地面为零势能面。并且要认真分析初末位置各有哪些能量，并用正确的公式表示。

2．变化量法：用变化量法列式时，不需要选择零势能面，但要正确表示出能量转化的关系。某种能量减小 （增加）时，一定有其它能量增加（减小）。
