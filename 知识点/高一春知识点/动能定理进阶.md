# 动能定理的应用
1．动能定理求做功：根据动能定理表达式：$W_{\text {合 }}=\Delta E_{\mathrm{k}}=E_{\mathrm{k}}-E_{\mathrm{k}}$ 初，可求出合外力做的功；再根据：$W_{\text {合 }}=W_1+W_2+W_3+\ldots$ ，可利用已知力做功求出未知力所做的功。

2．动能定理解决多过程问题：利用动能定理解决多过程运动的问题，重点在于选择合适的物理过程。所谓 ＂合适＂是指此过程的初状态和末状态动能已知或可利用已知条件求解；或者该段过程中各力的功便于计算求解。

3．动能定理结合圆周运动：动能定理经常与圆周运动综合，在一个圆周运动的过程中往往需要列动能定理，而在这个过程的初、末状态需要用瞬时牛顿第二定律，由该点的受力求解该点的瞬时速度，从而求得该点动能，为动能定理提供初、末状态参量。

4．动能定理处理往复运动：考察动能定理和往复运动相结合的问题，这种题目往往涉及到摩擦力做功，一般考察利用动能定理表达式求解摩擦力做的总功，从而求出物体在粗糙表面上运动的路程，并据此推测物体的位置。
# 动能定理结合图像
在动能定理结合图像的问题中，以 $E_k-x$ 图像较为常见，根据动能定理：$F_{\text {合 }} x=\Delta E_k$ ，不难发现 $\frac{\Delta E_k}{\Delta x}=F_{\text {合 }}$ ，也就是说，$E_k-x$ 图像的斜率可以代表合外力。
# 动能定理处理机车启动问题
1．恒定功率启动：$P_{\text {额 }} t-f s=\frac{1}{2} m v_m^2$（ $t$ 为以额定功率运行的时间）；

2．恒定加速度启动：$F_{\text {查 }} x_1+P_{\text {额 }} t-f s=\frac{1}{2} m v_m^2$（ $t$ 为以额定功率运行的时间，$F_{\text {芧为匀加速过程中的 }}$牵引力）。
