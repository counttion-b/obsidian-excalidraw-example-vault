# 圆周运动物理量
## 匀速圆周运动：
（1）定义：沿着圆周，并且线速度的大小处处相等的运动．

（2）性质：线速度的方向是时刻变化的所以是变速运动．

（3）条件：合外力大小不变、方向始终与速度方向垂直且指向圆心．

## 供需关系（合外力与向心力的关系）
![[Pasted image 20260329003824.png|200]]

（1）若 $F_{\text {合 }}=m r \omega^2$ 或 $F_{\text {合 }}=\frac{m v^2}{r}$ ，物体做匀速圆周运动．

（2）若 $F_{\text {合 }}>m r \omega^2$ 或 $F_{\text {合 }}>\frac{m v^2}{r}$ 物体做半径变小的近心运动．

（3）若 $F_{\text {合 }}<m r \omega^2$ 或 $F_{\text {合 }}<\frac{m v^2}{r}$ ，则外力不足以将物体拉回到原轨道上，而做离心运动．

（4）若 $F_{\text {合 }}=0$ ，则物体做直线运动．
