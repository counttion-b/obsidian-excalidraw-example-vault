# 第5讲 功和功率 #h0
# 知识讲解

## 功

### 做功的条件

1. 物理意义：功是能量转化的量度，是力在空间上的积累效应。

2. 做功的条件：

（1）作用在物体上的力；

（2）力的作用点在力的方向上发生位移。

3. 功的单位：“焦耳”，简称“焦”，符号“$J$”。

### 做功的计算

1. 功的定义：力对物体所做的功，等于力的大小、位移的大小、力与位移夹角的余弦值这三者的乘积。

2. 公式：$W=Fl\cos\alpha$。

3. 功的单位换算：$1J=1N\cdot m=1kg\cdot m^{2}/s^{2}$。

4. 条件：只适用于恒力做功。

### 正功与负功

1. 正、负功的判断：

（1）当$\alpha =\frac{ \pi }{2}$时，$\cos \alpha =0$，$W=0$。这说明力不做功。

（2）当$\alpha <{}\frac{ \pi }{2}$时，$\cos \alpha >0$，$W>0$。这说明力做正功。

（3）当$\alpha >\frac{ \pi }{2}$时，$\cos \alpha <{}0$，$W<{}0$。这说明力做负功。

2. 正、负功的物理意义：

（1）力对物体做正功：代表该力提供动力，向物体提供能量；

（2）力对物体做负功：也称物体克服该力做功，代表该力提供阻力，消耗物体的能量。

3. 功的标量性：标量；正负号代表能量的流向，属于双向标量，比大小看绝对值。

4. 变力做功正负的判断：若在某一过程中，力的方向和运动的方向一直发生变化，则可根据力与瞬时速度的夹角，判断做功的正负。

（1）力与瞬时速度方向夹角为锐角，做正功；

（2）力与瞬时速度方向夹角为钝角，做负功；

（3）力与瞬时速度方向夹角为直角，不做功。

### 总功的计算

1. 在计算总功时，可以先对物体进行受力分析，求出物体所受到的合外力，再找出物体某段过程中的位移，结合公式$W_{合}=F_{合}x\cos\theta$，即可求这段过程中的总功。

2. 在计算总功时，也可以先求出各个分力做的功，然后再代数求和，最终算出总功，即：

$W_{合}=W_{1}+W_{2}+W_{3}+...\ ...$ 。

## 功率

### 平均功率

1. 功率：

（1）物理意义：功率是反映物体做功快慢的物理量；

（2）定义：一个力所做的功跟完成这些功所用时间的比值叫做功率，即$P=\frac{W}{t}$，单位是$W$，$1W=1J/s$。

2. 平均功率：

（1）物理意义：表示在一段时间中力做功的平均快慢程度；

（2）定义式：$\overline{P}=\dfrac{W}{t}$。

### 瞬时功率

1. 物理意义：表示力在某一瞬间做功的快慢程度；

2. 公式：$P=\dfrac{W}{\Delta t}=\dfrac{F\Delta x\cos\theta}{\Delta t}=Fv\cos\theta$（式中$v$是瞬时速度，$\cos \theta$是力与速度的夹角的余弦值）。
