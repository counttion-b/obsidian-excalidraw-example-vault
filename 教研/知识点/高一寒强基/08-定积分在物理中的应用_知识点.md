# 知识讲解

## 定积分的含义

在之前学习的微元法中，我们将不规则图形切割为很多规则的小块以求其面积，并推广到一般的过程中。其核心思想是将不好直接求解的过程分为很多可以求解的过程后，对所有过程求和，再对过程取极限。这种思想是十分重要的，它给出了大部分一般性问题的求解方法，但相对来说比较繁琐，因此我们引入定积分的概念对其进行简化。

作为一个物理学人，我们几乎可以（不严谨地）认为，如果之前的求和过程中，每一小份都是无限小的小微元，且求和的结果是存在且有限的，那么我们就把这样一个小量求和的过程称为定积分，记作：

$\int_{a}^{b}{f(x) {\rm d}x}=\underset{\Delta x\to 0}{\mathop{\lim }}\,\sum\limits_{i=1}^{n}{f({{x }_{i}})\Delta {{x}_{i}}}$

在记号$\int_{a}^{b}{f(x){\rm d}x}$中，称：$f(x)$为被积函数，$x$为积分变量，$f(x){\rm d}x$为被积表达式，$a$、$b$为积分的下限与上限。定积分运算实际上就是在做小量求和。

高中阶段涉及到的微元求和，就是定积分。

如：一个求和式

$f ( c _ { 1 } ) \Delta x _ { 1 } + f ( c _ { 2 } ) \Delta x _ { 2 } + \cdots + f ( c _ { a - 1 } ) \Delta x _ { n - 1 } + f ( c _ { n } ) \Delta x _ { n }$

采用求和符号写成

$\sum _ { k = 1 } ^ { n } f ( c _ { k } ) \Delta x _ { k }$

上述求和共有n项,在$a \leq x \leq b$区间上共有n个子区间,和式中每一项都属于一个子区间。即每一子区间都有一项。

如把区间$a \leq x \leq b$分成长度越来越小的子区间,则子区间的数目也就越来越大。随着子区间数目n的增加,子区间长度 $\Delta x _ { k }$越来越小,此过程可书写为$\Delta x _ { k } \rightarrow 0$

在 $\Delta x _ { k }$→0的(极限)条件下,取上式的极限，该和式极限是个数,用A表示这个和的极限值,于是

$A = \lim _ { \Delta x _ { k } \rightarrow 0 } \sum _ { k = 1 } ^ { n } f ( c _ { k } ) \Delta x _ { k }$

按定积分的定义,数值A就是函数f(x)在区间$a \leq x \leq b$上的定积分。定积分表示为

$A = \int _ { a } ^ { b } f ( x ) d x$

上式中,数a称为积分下限,数b称为积分上限,x称为积分变量。

## 原函数与牛顿-莱布尼茨公式

显然，前面所介绍的通过“分割、求和、取极限”的方式来计算定积分是非常繁琐的。我们这里介绍定积分一个十分特殊而重要的性质：

设函数$f$在$[a,b]$连续，则函数$F(x)=\int_{a}^{x}{f(t){\rm d}t}$在$(a,b)$上可导，且导数（导函数）为

${F}’(x)=f(x)$，$x\in (a,b)$,

这就是微积分基本定理的微分形式，其中$F(x)$被称为$f(x)$的原函数。注意$\int_{a}^{x}{f(t){\rm d}t}$是“变上限”的定积分，它自然是上限的函数！这一积分的性质给出了求导和积分之间的一个互逆关系，即

$\frac{d}{dx}\int_{a}^{x}{f(t){\rm d}t}=f(x)$

同时，这一性质也帮助我们大大简化了定积分的运算。

从这条定理还可以得到它的积分形式，即：

设$\Phi (x)$在$[a,b]$上可微，且$\dfrac{\text{d}\Phi (x)}{\text{d}x}$等于连续函数$f(x)$，则

$\int _{a}^{x}f(t)\text{d}t=\Phi (x)-\Phi (a)\ \ (a\leqslant x\leqslant b)$.

将它写为一般形式，也即：

设$f$是$[a,b]$上的连续函数，$F(x)$是$f(x)$的一个原函数，则

$\int_{a}^{b}{f(x){\rm d}x}=F(b)-F(a)$.

这就是微积分基本定理的积分形式，也被称为牛顿-莱布尼茨公式，在上式中，常简记$F(b)-F(a)$为$\left. F(x) \right|_{a}^{b}$，即

$\int_{a}^{b}{f(x){\rm d}x}=\left. F(x) \right|_{a}^{b}$.

微积分基本定理将定积分的计算从小量求和转换为求原函数，就是将积分和微分联系了起来，在简化了计算的同时使得运用定积分来解决物理问题称为可能。

## 定积分的两个性质

1.  $\int _ { a } ^ { b } f ( x ) d x = - \int _ { b } ^ { a } f ( x ) d x$

即定积分的积分上下限交换时,积分值改变符号。

2.  $\int _ { a } ^ { b } f ( x ) d x = \int _ { a } ^ { c } f ( x ) d x + \int _ { c } ^ { b } f ( x ) d x$

其中，点c可以在a,b之间，也可以a,b之外。

## 定积分的基本运算法则

定积分的一般运算规则和不定积分类似，需要注意的一点是对定积分上下限的把握，包括上下限的交换与拆分，以及换元时上下限的变化。

（1）积分上下限相等及交换运算

定义积分原先要求$a<b$，为了运算和应用方便，我们补充规定：

①当积分上下限相同时，即$a=b$那么

$\int_{a}^{a}{f(x){\rm d}x}=0$

②当$a>b$时

$\int_{a}^{b}{f(x){\rm d}x}=-\int_{b}^{a}{f(x){\rm d}x}$

（2）线性运算法则

对于任何常数$\alpha$、$\beta$，$\alpha f+\beta g$也是$[a,b]$上的可积函数，且

$\int_{a}^{b}{[\alpha f(x)+\beta g(x)]{\rm d}x}=\alpha \int_{a}^{b}{f(x){\rm d}x}+\beta \int_{a}^{b}{g(x){\rm d}x}$

（3）定积分的拆分

对任何一点$c$，满足

$\int_{a}^{b}{f(x){\rm d}x}=\int_{a}^{c}{f(x){\rm d}x}+\int_{c}^{b}{f(x){\rm d}x}$

（4）定积分的换元法

设$f(x)$是$[a,b]$上的连续函数，而$\varphi (t)$是定义在$[\alpha,\beta]$上的一个可微函数，并满足

（1）$\varphi ^{'}(t)$是连续函数；

（2）$\varphi (t)$的值都在$[a,b]$上；

（3）$\varphi (\alpha)=a,\ \varphi (\beta)=b$；

则有

$\int _{a}^{b}f(x)\text{d}x=\int _{\alpha}^{\beta}f(\varphi (t))\varphi ^{'}(t)\text{d}t$.

定积分的换元法在形式上和原理上与不定积分相同，需要注意的是当积分变量改变后，积分的上下限也要相应地改变。当然也可以先用不定积分求出原函数后再计算定积分，从而回避积分上下限的变化。

（5）定积分的分部积分法

如果$u^{'}(x)$及$v^{'}(x)$是$[a,b]$上的连续函数，那么有

$\int _{a}^{b}u(x)v^{'}(x)\text{d}x=u(x)v(x)|_{a}^{b}-\int _{a}^{b}v(x)u^{'}(x)\text{d}x$,

这和不定积分的分部积分法基本相同。

## 分离变量法解微分方程

在物理问题中，有些时候物理量的函数关系不能直接写出来，而是要根据具体问题的条件和某些物理定律，得到一个或几个含有未知函数微分的关系式，这就是微分方程。

满足微分方程的函数称为微分方程的解，若这个解含有$n$个独立的任意常数$C_1,C_2,C_3\cdots C_n$，则称它为通解，若不含任何常数，称为特解。从物理问题提出微分方程时，往往还有附加条件，这就是定解条件，如果给的是运动（或变化）的初始状态，称为初始条件。带有初始条件的微分方程求解问题，称为初值问题。

求解微分方程的基本原则是将微分方程处理成如下形式

$f(x)\mathrm{d}x = g(y)\mathrm{d}y$

左右两侧同时积分，得到$x$和$y$的函数关系，这个方法叫做分离变量法。

以气垫导轨上小滑块的运动为例，导轨水平时，滑块运动方向上仅受空气阻力$f=-kv$作用，牛顿运动定律可写成

$m\frac{\mathrm{d}v}{\mathrm{d}t}=-kv$

分离变量可得

$\frac{\mathrm{d}v}{v}=-\frac{k}{m}\mathrm{d}t$

两边同时做不定积分

$\ln{v}=-\frac{k}{m}t+C$

若滑块初始速度为$v=v_0$，则有$C=\ln{v_0}$，即

$v=v_0e^{-\frac{k}{m}t}$

在一些比较复杂的微分方程中可能不能直接分离变量，此时可以利用积分中讲过的换元法来使方程的形式得到简化。
