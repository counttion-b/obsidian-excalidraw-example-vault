## 普朗克黑体辐射理论
### 黑体

1 ．黑体：如果某种物体能够完全吸收入射的各种波长的电磁波而不发生反射，这种物体就是绝对黑体，简称黑体 。
![[Pasted image 20260403132408.png]]

**一个带小孔的空腔可以近似看成黑体**

2 ．黑体辐射：黑体虽然不反射电磁波，却向外辐射电磁波，这样的辐射叫做黑体辐射。
3 ．能量子：振动着的带电微粒的能量只能是某一最小能量值 $\varepsilon$ 的整数倍．当带电微粒辐射或吸收能量时，也是这个能量值为单位一份一份的辐射或者吸收的．这个不可再分的能量值 $\varepsilon$ 叫做能量子．

4 ．能量子公式 ：$\varepsilon=h \nu$ ．（ $\nu$ 是电磁波的频率，$h=6.626 \times 10^{-34} \mathrm{~J} \cdot \mathrm{~s}$ ）
5 ．能量的量子化：在微观世界中能量不连续变化，只能取分立值，这种现象叫做能量的量子化．

## 光电效应
### 光电效应

19世纪末，人们发现光照射在金属表面上时，金属中的电子吸收光的能量而逸出金属表面，这就是光电效应现象。
![[Pasted image 20260403132456.png|300]]
### 爱因斯坦光电效应方程

（1）光子说：光不仅在发射和吸收时能量是一份一份的，而且光本身就是由一个不可分割的能量子组成的，这些能量子称为光子；
$\varepsilon=h \nu, h=6.626 \times 10^{-34} \mathrm{~J} \cdot \mathrm{~s}, h$ 为普朗克常量，$\nu$ 为光的频率
意义：
（1）光子说很好地解释了光电效应；
（2）光由大量的光子构成，光具有粒子性．
（2）逸出功 $W_0$ ：电子从金属中逸出所需做功的最小值。
（3）最大初动能：发生光电效应时，金属表面上的电子吸收光子后克服原子核的引力逸出时所具有的动能的最大值。
（4）光电效应方程
（1）表达式：$h v=E_k+W_0$ 或 $E_k=h v-W_0$
（2）物理意义：金属表面的电子吸收一个光子获得的能量是 $h_v$ ，这些能量的一部分用来克服金属的逸出功 $W_0$ ，剩下的表现为逸出后电子的最大初动能。

注意：光电效应发生时，每个电子只能吸收一个光子
### 光电效应实验

（1）光电效应的产生条件
入射光的频率大于金属的截止频率。
（2）光电效应注意事项
①每种金属都有一个截止频率，入射光的频率必须大于这个极限频率才能产生光电效应。
②光电子的最大初动能与入射光的强度无关，只随入射光频率的增大而增大。
③光电效应的发生几乎是瞬时的，一般不超过 $10^{-9} s$
④当入射光的频率大于极限频率时，饱和光电流的大小与入射光的强度成正比。

### 正确理解光电效应中的五组概念
（1）光子与光电子：光子指光在空间传播时的每一份能量，光子不带电；光电子是金属表面受到光照射时发射出来的电子，其本质是电子。光子是光电效应的因，光电子是果。
（2）光电子的动能与光电子的最大初动能 ：光照射到金属表面时，电子吸收光子的全部能量，可能向各个方向运动，需克服原子核和其他原子的阻碍而损失一部分能量，剩余部分为光电子的初动能；只有金属表面的电子直接向外飞出时，只需克服原子核的引力做功的情况，才具有最大初动能。光电子的初动能小于等于光电子的最大初动能。
（3）光电流和饱和光电流：金属板飞出的光电子到达阳极，回路中便产生光电流，随着所加正向电压的增大，光电流趋于一个饱和值，这个饱和值是饱和光电流，在一定的光照条件下，饱和光电流与所加电压大小无关。
（4）入射光强度与光子能量：入射光强度指单位时间内照射到金属表面单位面积上的总能量。而光子能量 $E=h v_0$
（5）光的强度与饱和光电流：饱和光电流与入射光强度成正比的规律是对频率相同的光照射金属产生光电效应而言的，对于不同频率的光，由于每个光子的能量不同，饱和光电流与入射光强度之间没有简单的正比关系。
### 光电效应的两条线索

（1）两条线索

$$
\left\{\begin{array}{l}
\text { 照射光 }\left\{\begin{array}{l}
\text { 强度——决定着每秒钟光源发射的光子数←—决定着每个光子的能量 } \varepsilon=h \nu \\
\text { 光电子 }\left\{\begin{array}{l}
\text { 每秒钟逸出的光电子数——决定着光电流的大小 } \\
\text { 光电子逸出后的最大初动能 } \frac{1}{2} m v^2
\end{array}\right.
\end{array} \right.
\end{array}\right.
$$

（2）两条对应关系
（1）光强大 → 光子数目多 → 发射光电子多 → 光电流大；
（2）光子频率高 → 光子能量大 → 光电子的最大初动能大。

## 波粒二象性

### 康普顿效应

X 射线经过石墨等物质散射时，在散射的 X 射线中除了有与入射波长 $\lambda_0$ 相同的成分，还有波长大于 $\lambda_0$的成分．这种波长变长的现象即为康普顿效应．
![[Pasted image 20260403133113.png|300]]

康普顿的解释：X射线散射后波长改变，是由于X射线光子与物质中电子的碰撞的结果。碰撞前后动量和能量守恒，电子动量和能量都增加，光子动量能量减少，散射后光子频率减小，波长变大．
