# 3. 机械波 #h0
# 知识讲解

## 波的形成和传播

1. 波：振动的传播称为波动，简称波。

![[5a845388-4bf0-435f-85af-5c3290e60826.png|300]]

 在艺术体操的带操表演中，运动员手持细棒抖动彩带的一端，彩带随之波浪翻卷。彩带上的波浪翻卷实际是振动在彩带上传播的结果。

2. 机械波的产生条件：绳波是通过绳来传播的，声波通常是通过空气中传播的。绳、气等是波借以传播的物质，叫做介质。

能够维持振动的传播，不间断的输入能量，并能发出波的物体或物体所在的初始位置叫做波源。组成介质的质点之间有相互作用，一个质点的振动会引起相邻质点的振动。机械振动在介质中的传播，形成了机械波。例如用手抖动的彩带端叫波源，彩带为传播振动的介质。

所以机械波产生的条件是波源和介质。

![[ecdc5a4b-9cf0-4c39-bbf0-c3827690d51b.png|300]]

3. 建模与分析：一条绳子可以分成一个个小段，一个个小段可以看做一个个相连的质点，这些质点之间存在着相互作用。当手握绳端上下振动时，绳端带动相邻的质点，使它也上下振动。这个质点又带动更远一些的质点跟着振动起来，只是后面的质点总比前面的质点迟一些开始振动。这样，绳端这种上下振动的状态就沿绳子传出去了，从整体上看，就是一些凹凸相同的波形。

在下图中，可更清晰地描绘绳中质点的运动与波的传播关系：

![[3519ada2-575f-4a5d-8970-c31c549f94a2.png|300]]

最上面一行中的圆点代表绳中的质点，相邻质点之间有相互作用力，这使得一个质点的运动会影响相邻质点的运动。

质点${{P}_{0}}$沿上下方向振动，依次牵动质点${{P}_{1}}$，${{P}_{2}}$，${{P}_{3}}$，$\cdots$使它们也运动起来。在$t=\frac{1}{4}T$时刻，质点${{P}_{0}}$到达了最高点，而${{P}_{2}}$刚刚要开始运动。质点${{P}_{0}}$到达最高点后又开始下落，当$t=\frac{1}{2}T$时它又回到平衡位置，而这时${{P}_{2}}$刚刚到达最高点，质点${{P}_{4}}$刚刚要开始运动。其他几个图是随后几个时刻各质点的运动情况。

4. 波的本质：波是能量传播的一种方式。机械波向外传播的只是振动形式，介质上的各个质点都在自己的平衡位置附近振动，并不随波迁移。

例如绳上或弹簧上有波传播时，它们的质点发生振动，但质点并不随波迁移，传播的只是振动这种运动形式。

## 波的分类

1. 横波：质点的振动方向与波的传播方向垂直。横波中，凸起的最高处叫波峰，凹下的最低处叫波谷。

![[c54b4c10-e967-46d0-836b-a07cca541891.png|300]]

2. 纵波：质点的振动方向与波的传播方向在同一直线上。纵波中，质点分布最密的地方叫密部，分布最疏的地方叫疏部。

![[732e20fb-0f76-42c0-ac85-72006d3492a1.png|300]]

## 机械波的描述

### 描述波的物理量

1. 波长$\lambda$：

（1）定义：在波动中，振动步调（振动相位）总是相同的两个相邻质点间的距离，叫做波长，通常用$\lambda$表示。

（2）特征：在横波中，两个相邻波峰或两个相邻波谷之间的距离等于波长。在纵波中，两个相邻密部或两个相邻疏部之间的距离等于波长。

![[3281e4f1-4213-494f-99e6-141092de8315.png|300]]

2. 周期$T$和频率$f$：

（1）定义：波上各质点的振动周期(或频率)。

（2）规律：在波动中，介质中各个质点的振动周期（或频率）都是相同的，它们都等于波源的振动周期（或频率）。这个周期或频率也叫做波的周期$T$或频率$f$。波的频率由振源决定，与介质无关。

（3）关系：周期$T$和频率$f$互为倒数，即$f＝$$\dfrac{1}{T}$。

3. 波速$v$：

（1）定义：机械波在介质中传播的速度叫做波速。经过一个周期，振动在介质中传播的距离等于一个波长，因此波速等于波长和周期的比值。

（2）定义式：$v＝$$\dfrac{\lambda}{T}$$＝λf$。

（3）决定因素：机械波在介质中的传播速度由介质本身的性质决定，与振源无关。在不同的介质中，波速一般不同。另外，波速还与温度有关。

0℃时几种介质中的声速$v/\left( \text{m}\centerdot {{\text{s}}^{-1}} \right)$
![[Pasted image 20260401221223.png]]

4. 总结：

（1）在简谐波中，各质点的振幅、周期、频率都相同，振动频率都等于波源的振动频率。

（2）后一质点（离波源远的质点）的振动滞后于前一质点（离波源近的质点）的振动。

（3）在同一种均匀介质中机械波的传播是匀速的。

（4）介质质点的运动是在各自的平衡位置附近的简谐运动，是变加速运动，介质质点并不随波迁移。

（5）机械波传播的是振动形式、能量和信息。

### 波的图像

1. 波的图像：也称波形图，简称波形，描述介质中各个质点在某一时刻的位移。如果波的图像是正弦曲线，这样的波叫做正弦波。

![[6948d587-4a7a-486a-80db-f1c1182ac660.png|300]]

2. 波的图像信息：

（1）横坐标——表示在波的传播方向上各质点的平衡位置；

（2）纵坐标——表示某一时刻各质点偏离平衡位置的位移；

（3）波的图像表示传播过程中各个质点在同一时刻偏离各自平衡位置的位移；

（4）图中提供的物理信息包括：波长，各质点当前的位置，各质点的振幅。

3. 波的图像特点：

（1）周期性：简谐波在传播过程中，波形随时间匀速平移，经时间$nT$后，波形又恢复原状。

（2）双向性：波的传播方向可能沿$x$轴正向，也可能沿$x$轴负向。

## 振动与波动联系与区别

1. 联系：

（1）振动是波动的原因，波动是振动的结果；

（2）有波动必然有振动，有振动不一定有波动；

（3）波动的频率与波源振动的频率相同。

 2. 区别：

（1）研究对象不同：振动研究的是单个质点在平衡位置附近的往复运动；波动研究的是介质中大量质点的集体振动。

（2）力的来源不同：产生振动的回复力，可以由作用在物体上的各种性质的力提供；引起波动的力，则总是介质中各质点间的相互作用力。

（3） 运动性质不同：各质点的振动，是变加速运动；在同一种介质中波动的传播速度不变。

## 波上任意点的振动方向的判断方法

1. 带动法：首先，明确波的传播方向，确定波源方位；然后在质点$P$靠近波源一方附近（不超过$\lambda /4$）图像上找另一点$P’$；若$P’$在$P$上方，则$P’$带动$P$向上运动，若$P’$在$P$下方，则$P’$带动$P$向下运动。

2. 微平移法：做出经微小时间$\Delta t\left(\Delta t < T/4 \right)$后的波形，就知道了各质点经过$\Delta t$时间到达的位置，运动方向就知道了。

![[1a70fe9f-edd2-4e99-b6fc-4819a326d296.png|300]]

3. 同侧法：在波的图像上的某一点，沿水平方向画一个箭头表示波的传播方向，并设想在同一点沿竖直方向画出一个箭头表示质点振动方向，那么这两个箭头总是在曲线的同侧，其中$s$表示质点振动方向，$v$表示波的传播方向。

![[670b5a87-a1e8-4a76-a18e-33f5fc3a2018.png|300]]

4. 上下坡法：沿波的传播方向看，“上坡”的质点向下振动，“下坡”的质点向上振动，简称“上坡下，下坡上”。

![[55b26a88-05fc-46c0-83f6-d64a1f0e4c76.png|300]]
