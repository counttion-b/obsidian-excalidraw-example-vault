## 链式法则

在处理实际问题时，遇到的函数形式往往不能由几个基本初等函数通过四则运算简单地表示，而有可能是由多个基本初等函数复合而成的，例如$y=\frac{1}{\sqrt{\sin x}}$就是由$y=x^{-1/2}$和$y=\sin x$复合而成的。所以在求导运算中，还需要掌握这种复合函数求导的法则。

如果函数$g(x)$在$x_0$处可导，函数$f$在$g_{0}=g\left( x_{0}\right)$处可导，则复合函数$f\left( g\left( x\right)\right)$在$x_0$处可导，且满足

$\boldsymbol{f'\left( x_{0}\right)=f'\left( g_{0}\right)g'\left( x_{0}\right)}$,

即先将函数$f(g(x))$对$g$求导，再乘以$g(x)$对$x$的导数。复合函数的求导法则也可以简单地记作：

$\frac{\text{d}y}{\text{d}x}=\frac{\text{d}y}{\text{d}u}\cdot\frac{\text{d}u}{\text{d}x}$

我们称之为链式法则。

## 微分的定义

通常把自变量$x$的增量$Δx$当作自变量的微分，记作$dx$,于是

$dx=Δx$

从数学上讲，微分$dx$是个无限小增量，但在实际应用中又常把有限小增量$△x$当作微分处理，这是一个既直观又方便的方法。

函数$y = f ( x )$的微分,常用dy或df表示,其简单定义如下:

$d f = \frac { d f } { d x } \cdot d x$

即函数f(x)的微分df等于函数的导数 $\frac { d f } { d x }$与自变量的微分dx之积。因而可记为

$d f = f ^ { \prime } ( x ) d x$

由于$y = f ( x )$,故f(x)的微分也可用符号dy表示,于是

$d y = f ^ { \prime } ( x ) d x = y ^ { \prime } d x$

由函数的微分定义可见,dy或df是由x和dx这两个量共同决定的。

物理上用得较多的是将导数用$dy$和$dx$的比值$\dfrac{dy}{dx}$来表示微分，微分可以进行加、减、乘、除(除数不为零)等运算。$d$这种符号是德国数学家莱布尼(Gottfried Wilhelm Leibniz)发明的。它们所表示的量无限趋近于零，但却不等于零，我们称之为微分。

莱布尼茨是根据这一思想定义切线的：让曲线上一个动的点无限靠近另一个不动的点，但两点始终不会重合。我们想想就知道，只有两个点才能确定一条直线，如果两个点重合了就没法确定直线了!

微分一词在此处看起来是一个名词，但随着我们后面学习积分，微分也表示将整体分割成微小的单元的意思，那时它也就成为一个动词了。

## 微商

把函数的微分定义式$d f = \frac { d f } { d x } \cdot d x$作一些变化，就可以得到用微分表示的导数，从而给出导数的一个新的表达式。

将式子两端同除以不为零的dx,则

$\frac { d y } { d x } = \frac { f ^ { \prime } ( x ) d x } { d x } = f ^ { \prime } ( x )$

这个表达式有重要意义,等式右端 $f$(x)是函数f(x)的导数,等式左端是函数的微分dy与自变量微分,dx之比 微分之比,以下简称微商。不难看出，导数即微商。

如，函数的微分为：$d y = ( 3 x ^ { 2 } ) d x$,

上式两端同除以dx,则有

$\frac { d y } { d x } = \frac { ( 3 x ^ { 2 } ) d x } { d x } = 3 x ^ { 2 }$

## 微分的运算法则

从微分的定义中就可以看出，它的运算法则会和导数的运算法则十分相似。对于可导函数$u$, $v$和常量$\alpha$, $\beta$，其微分的运算满足

$\text{d}(\alpha u\pm\beta v)=\alpha\text{d}u\pm\beta\text{d}v$,

$\text{d}(uv)=u\text{d}v+v\text{d}u$,

$\text{d}(\dfrac{u}{v})=\dfrac{v\text{d}u-u\text{d}v}{v^{2}},\ \ (v\ne0)$.

对于复合函数，其微分计算也和导数类似，即

$\text{d}(u(v(x)))=u^{'}(v)v^{'}(x)\text{d}x$.

根据微分的定义，$v^{'}(x)\text{d}x=\text{d}v$，因此上式也可写为

$\text{d}(u(v(x)))=u^{'}(v)\text{d}v$,

这也被称为微分形式的不变性。

## 微分在物理学中的应用

圆面积的微分是圆环的面积&dr&

设半径为r的圆的面积为A

$A = \pi r ^ { 2 }$

两端取微分,得

$d A = \frac { d A } { d r } d r = \frac { d } { d r } ( \pi r ^ { 2 } ) d r = 2 \pi r d r$

为说明dA的大小,画一个半径为r宽为dr的圆环

![[2d833dbe-8957-4358-b59b-c4db45ecba80.png|300]]

圆环面积等于两个半径分别为r+dr及r的圆面积之差,即

$\pi ( r + d r ) ^ { 2 } - \pi r ^ { 2 } = 2 \pi r d r + \pi ( d r ) ^ { 2 }$

上式中dr是半径的微分, $( d r ) ^ { 2 }$是半径微分的平方,因微分是小量,$( d r ) ^ { 2 }$子是小量的平方,它与2πrdr相比,属高阶小量,即

$\frac { \pi ( d r ) ^ { 2 } } { 2 \pi r d r } = \frac { d r } { 2 r } \ll 1$

只要满足上述条件,当计算圆环面积时,便可略去π(dr^{2}这项,因而圆环面积可视为2πrdr。严格地讲,圆面积的微分近似等于圆环的面积,圆环的宽度越小近似程度越高。

球体积的微分dV等于半径为r厚度为dr的球壳体积。

![[0691e864-2b45-41fe-b74c-2ef16dfbd039.png|300]]

设半径为r的球体积为V,则

$V = \frac { 4 } { 3 } \pi r ^ { 3 }$

对上式两端微分,得

$d V = \frac { d V } { d r } d r = 4 \pi r ^ { 2 } d r$

如图1$2 - 6$5所示的球壳体积是两个同心球体积之差,即

$\frac { 4 } { 3 } \pi ( r + d r ) ^ { 3 } - \frac { 4 } { 3 } \pi r ^ { 3 } = \frac { 4 } { 3 } \pi [ 3 r ^ { 2 } d r + 3 r ( d r ) ^ { 2 } + ( d r ) ^ { 3 } ]$

若dr很小,它的平方 $( d r ) ^ { 2 }$及三次方 $( d r ) ^ { 3 }$}就更小了,可以略去,由此可得

$\frac { 4 } { 3 } \pi \left[ 3 r ^ { 2 } d r \right] = 4 \pi r ^ { 2 } d r$

这就证明了,球体积的微分近似等于半径为r厚度为dr的球壳体积。

用微分即小量的观点看，上式的几何意义是,当球的半径r变化dr时,引起体积变化量$d V$恰好近似等于球壳的体积。推而广之,不论什么样的几何形体,其体积的微分近似等于体积的变化量。
