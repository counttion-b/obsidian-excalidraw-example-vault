# 第3讲 电势能和电势 #h0
# 知识讲解
初中我们学地理的时候学过海拔高度。所谓海拔高度就是某地与海平面的高度差。我们在上学期学习了重力势能，知道了同一物体在相对零势能面越高的地方拥有更多的重力势能，重力就能做更多的正功。
同样的，既然电场中有电场力，电场力就会做功。电场力做功和重力做功之间有什么关系？我们能不能像描述海拔高度一样描述电场中的能量高低呢？

## 1. 电场力做功
### 1.1. 电场力做功
如果将一个静止的检验电荷放入电场中，它会受到力的作用并运动起来，其动能会增加，而能量变化一定会对应着某种力做功，这里只有电场力，为了更好的研究电荷在电场中的能量问题，我们先从电场力的做功特点入手。
> [!question] 电场力做功的特点
如图所示，在匀强电场中检验电荷+q沿不同轨迹从A移动到B时电场力做的功？
![[Pasted image 20260712201422.png|700]]

通过上面的问题，我们发现**电场力对电荷做的功与路径无关**，与电场线方向的高度有关，即 $W=qE\left| AM\right|$，这和我们以前学过的重力做功的特点相似。重力做功必然引起重力势能的变化，那么电场力做功也一定会引起某种能量的变化。我们把这种能量叫做电势能。

## 2. 电势能
静止的电荷放入电场中会受到力的作用而运动，其动能会增加。根据能量守恒定律，一定是有一种能量减少转化为了电荷的动能，那到底是什么形式的能转化为试探电荷的动能？
### 2.1. 电势能的定义
我们定义:电荷在静电场中所具有的势能叫做静电势能，又称电势能，用符号 $E_p$ 表示.
### 2.2. 电场力做功与电势能的关系
1. 类比
我们学习过重力做功与重力势能的关系 $W_G=-\Delta E_{pG}$. 重力做正功重力势能 $\_\_\_\_\_\_$, 重力做负功重力势能 $\_\_\_\_\_\_$.那么电场力做功和电势能是否也是一样的关系?
2. 定性推导
（1）由动能定理，
$+q$ 从 $A$ 点由静止开始运动到 $B$ 点的过程中，电场力做＿＿＿＿功，$+q$ 的动能＿＿＿＿；
$+q$ 从 $B$ 点以某初速度向 $A$ 点运动的过程中，电场力做＿＿＿＿功，$+q$ 的动能＿＿＿＿；
（2）由能量守恒
$+q$ 从 $A$ 点由静止开始运动到 $B$ 点的过程中，动能＿＿＿＿，电势能＿＿＿＿；
$+q$ 从 $B$ 点以某初速度向 $A$ 点运动的过程中，动能＿＿＿＿，电势能＿＿＿＿；
（3）由以上两问可知： 
电场力做正功，电势能＿＿＿＿；
电场力做负功（或克服静电力做功），电势能＿＿＿＿.

### 2.3. 电势能的性质
1. 状态量: 电势能表示某一个瞬间带电体具有能量的多少.
2. 相对性:电势能是相对的, 具体数值与零势能面的选取有关
3. 系统性:电势能是为电荷和对他作用的电场组成的系统所共有的.
4. 标量性: 电势能是标量, 只有大小, 没有方向, 正(负)表示比零势能大 (小).

> $E_{p1}=3J$, $E_{p2}=-5J$, $E_{p1} \_\_\_\_\_\_ E_{p2}$

## 3. 电势
### 3.1. 类比地势
![[Pasted image 20260712210518.png|500]]
山脚虽然高度低, 但有一个质量大的物体, 所以重力势能大, 山顶虽然高度高, 有个质量小的物体, 所以重力势能小.
如果我们希望比较地势的高低, 好像不能通过重力势能来比较, 因为重力势能会被试探物体的质量所影响.而是应该刨去物体质量的影响, 才能看到重力场中地势的性质.
同样的,我们需要引入一个物理量来描述电场中不同点的能的性质的不同。与电场强度定义类似，我们来考查在一个电场中的同一点放入不同电荷量的试探电荷，试探电荷所具有的电势能有什么规律？
### 3.2. 电势的推导
在场强为E的匀强电场中，定义O点为零势能点，三个电量分别+1C、+2C、-2C的点电荷从O点运动到A点，OA的长度等于L，求：
![[Pasted image 20260712210900.png]]
1. 电场对三个电荷分别做了多少功？
2. 三个点电荷在A的电势能是多少？
3. 电势能 $E_{P}$ 与电量$q$的比值？
> [!abstract] 结论
通过上面的分析，我们发现场中某点的电势能和电量的比值与电荷量的大小无关，而与电场本身和点电荷所处位置有关。我们把这样的比值叫做该点的电势。用$\varphi$表示。

### 3.3. 电势的定义
1. 物理意义：电势是描述电场能的性质的物理量，由电场本身决定，与试探电荷无关。
2. 定义：电荷在电场中某点的电势能与它的电荷量的比值，叫作这一点的电势。
3. 表达式：
$\varphi=\frac{E_p}{q}$
4. 单位：伏特，符号是 $\mathrm{V}$。
$1\ \mathrm{V}=1\ \mathrm{J/C}$
5. 性质：
   -  电势是反映电场自身性质的物理量，它**仅由电场决定**，**与试探电荷无关**。
   -  电势具有**相对性**，通常取距离场源电荷无穷远处或大地为零电势点。
   -  电势是**标量**，只有大小，没有方向。正(负)代表比零电势高 (低)
> [!question] 电势比大小
> $\varphi_{1}=3J$, $\varphi_{2}=-5J$, $\varphi_{1} \_\_\_\_\_\_ \varphi_{2}$
### 3.4. 场势关系
如图所示，$A、B$ 为点电荷形成的电场中的一条电场线上的两个点。请根据下列不同情况，分别比较 $A、B$ 两点间的场强 $E$、电势能 $E_p$ 及电势 $\varphi$ 的大小关系。
![[Pasted image 20260712211844.png]]
1. 若场源电荷为 $+Q$，试探电荷为 $+q$，则：  
$E_A\_\_\_E_B,\qquad E_{pA}\_\_\_E_{pB},\qquad \varphi_A\_\_\_\varphi_B$
2. 若场源电荷为 $+Q$，试探电荷为 $-q$，则：  
$E_A\_\_\_E_B,\qquad E_{pA}\_\_\_E_{pB},\qquad \varphi_A\_\_\_\varphi_B$
3. 若场源电荷为 $-Q$，试探电荷为 $+q$，则：  
$E_A\_\_\_E_B,\qquad E_{pA}\_\_\_E_{pB},\qquad \varphi_A\_\_\_\varphi_B$
4. 若场源电荷为 $-Q$，试探电荷为 $-q$，则：  
$E_A\_\_\_E_B,\qquad E_{pA}\_\_\_E_{pB},\qquad \varphi_A\_\_\_\varphi_B$

## 4. 电势差
### 4.1. 电势差的定义
地面凹凸不平, 有的海拔高, 有的海拔低, 存在地势差.
1. 同样的,电场中两点电势的差值叫做电势差，也叫电压，用 $U$ 表示，即a、b两点间的电势差：$U_{ab}=\varphi_{a}-\varphi_{b}$
2. 电势差的单位是：伏特V。
3. 电势差的特点
	1. 绝对性:电势差 $U_{ab}$ 的值与零势能位置无关，电势差具有绝对性，且有 $U_{ab}=-U_{ba}$；
	2. 电势差是标量.
### 4.2. 电势差与电场力做功的关系

那么电场力做功看的就是两点之间的电势差.
