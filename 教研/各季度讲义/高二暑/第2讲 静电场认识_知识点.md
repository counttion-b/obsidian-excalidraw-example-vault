# 第2讲 静电场认识 #h0


# 知识讲解

## 1. 场概念的提出
![[Pasted image 20260712160924.png]]
我们知道，任何两个有质量的物体之间都存在万有引力。

1. 那么，即使两个物体相隔极其遥远，甚至分别位于宇宙的两端，它们之间仍然存在万有引力吗？假如其中一个物体的质量突然发生变化，另一个物体所受的引力也会在同一瞬间发生变化吗？如果引力可以瞬间跨越遥远的空间，就意味着相距数百亿光年的两个物体能够立刻“得知”对方的变化，这显然令人难以理解。牛顿也曾为这一问题感到困惑。虽然他同样认为这种瞬时作用并不自然，但受当时科学条件的限制，只能暂时将万有引力看作一种不需要中间媒介的“超距作用”。

2. 现代物理认为，物体并不是隔着遥远的空间直接对另一个物体施加作用，而是先在周围空间中形成一种特殊的物质——**场**，再由场对处于其中的其他物体产生作用。

3. 其实,场这个概念,是19 世纪 30 年代，英国科学家法拉第在研究电时首次提出的。与有质量的物体会在周围产生引力场类似，带电体也会在周围空间中产生**电场**。带电体吸引轻小物体，以及电荷之间的相互吸引或排斥，都可以理解为电场对其中电荷产生作用的结果。

4. 接下来，我们将以静电场为例，研究场的基本性质。

## 2. 电场和电场强度
### 2.1. 电场的基本性质
电荷之间的相互作用并不是直接发生的，而是通过电场实现的：电荷在周围空间产生电场，电场再对处于其中的其他电荷产生作用。
1. 定义：电荷周围存在一种特殊物质，这种物质能够传递电荷之间的相互作用，称为**电场**。
2. 基本性质：电场对放入其中的电荷具有力的作用，这种力称为**静电力**或**电场力**。
3. 物质性：电场是一种客观存在的特殊物质，具有能量、动量等物质的基本属性，但不同于通常所说的实物粒子。
4. 静电场：由静止电荷产生的电场，称为**静电场**。



### 2.2. 探究场的性质
看不见摸不着的场, 如何研究?
1. 场的基本理解
- 场强**由场源决定，与试探者无关**
- 场中不同位置，场强不同，某点场强与该点距场源的位置有关
- 场的作用效果**由场源、位置和试探者共同决定**


2. 场源电荷：产生电场的电荷（在本章中，我们只讨论静止电荷产生的电场-称为静电场）
3. 试探电荷：电量较小、体积较小，对场源没有干扰的电荷，又叫检验电荷。
4. 探究电场的性质
若保持 $r$ 不变，即同一位置下探究场源电荷在该点产生的电场
（1）当放入试探电荷 $q_1$ 时，求 $q_1$ 所受电场力的大小
（2）当放入试探电荷 $q_2$ 时，求 $q_2$ 所受电场力的大小
（3）分别计算以上两种情况下，试探电荷受到的电场力与其电荷量的比值由此可知不同的试探电荷放在电场中某处时的受力 $\_\_\_\_$ ，但力与试探电荷电量的比值是个 $\_\_\_\_$ ，由 $\_\_\_\_$ 和 $\_\_\_\_$ 决定，与 $\_\_\_\_$ 无关。
### 2.3. 电场强度
1. 物理意义：用来描述电场力的性质的物理量，反映电场自身性质的物理量，由场决定，与试探电荷无关。
2. 定义：在电场中的某一点放入电荷量为 $q$ 的试探电荷，若它受到的电场力为 $F$，则电场力 $F$ 与试探电荷电荷量 $q$ 的比值，叫作该点的**电场强度**，简称场强，用符号 $E$ 表示。
$$
E=\frac{F}{q}
$$
3. 单位：在国际单位制中，电场强度的单位为 $\mathrm{N/C}$，也可以写作 $\mathrm{V/m}$。
4. 矢量性：电场强度是矢量。
5. 方向：电场中某点的电场强度方向，规定为**正电荷在该点所受电场力的方向**。若放入的是负电荷，则负电荷所受电场力的方向与该点的电场强度方向相反。
6. 唯一性：在电场中的某一点，电场强度的大小和方向都是唯一确定的。

### 2.4. 点电荷的场强
![[Pasted image 20260712160643.png|600]]
1. 推导：
由库仑定律$F=k\frac{Qq}{r^2}$以及电场强度的定义$E=\frac{F}{q}$可得$E=k\frac{Q}{r^2}$
2. 表达式：$E=k\frac{Q}{r^2}$
其中，$Q$ 为场源电荷的电荷量，$r$ 为该点到场源电荷的距离。
3. 方向：
   - 场源电荷为正电荷时，场强方向沿场源电荷与该点的连线，指向远离场源电荷的方向。
   - 场源电荷为负电荷时，场强方向沿场源电荷与该点的连线，指向场源电荷。
4. 适用条件：真空中的静止点电荷。

## 3. 电场的叠加
1. 叠加原理：当空间中同时存在多个场源电荷时，它们产生的电场相互叠加，形成合电场。
2. 计算方法：某点的合场强等于各个场源电荷单独存在时在该点产生的场强的矢量和。$\vec E=\vec E_1+\vec E_2+\cdots+\vec E_n$
3. 运算法则：电场的叠加遵循平行四边形定则。

### 4.2. 电场线的性质
![[Pasted image 20260712164022.png|800]]
1. 电场线从正电荷或无限远出发，终止于无限远或负电荷。

## 5. 常见电场的特点
### 5.1. 正点电荷的电场

1. 形状：以点电荷为中心，沿各个方向向外发散，呈“光芒四射”状。
2. 方向：由正点电荷指向无穷远。
3. 场强特点：以点电荷为球心的同一球面上，各点到点电荷的距离相等，因此场强大小相等，但方向不同。
### 5.2. 负点电荷的电场
1. 形状：从各个方向向点电荷会聚，呈“众矢之的”状。
2. 方向：由无穷远指向负点电荷。
3. 场强特点：以点电荷为球心的同一球面上，各点场强大小相等，但方向不同。

### 5.3. 等量同种点电荷的电场
1. 整体形状：两电荷的电场线相互排斥，呈“势不两立”状。
2. 连线中点：两电荷连线中点 $O$ 处，两电荷产生的场强等大反向，合场强为零。
3. 中垂线：在两电荷连线的中垂线上，关于 $O$ 点对称的两点场强大小相等、方向相反。
4. 场强变化：从 $O$ 点沿中垂线向无穷远移动，场强先增大后减小。

### 5.4. 等量异种点电荷的电场
1. 整体形状：电场线从正电荷出发，终止于负电荷，整体呈相吸状。
2. 连线上：两电荷连线上各点的场强方向均由正电荷指向负电荷。
3. 中垂线上：场强方向与两电荷连线平行，并由正电荷一侧指向负电荷一侧。
4. 对称性：电场线关于两电荷连线以及其中垂线对称。

### 5.5. 平行板电容器的电场
1. 定义：如果电场中各点的电场强度大小相等、方向相同，这个电场叫作**匀强电场**。
2. 常见实例：相距很近、带有等量异种电荷的一对平行金属板之间的电场，除边缘附近外，可以近似看作匀强电场。
3. 特点：匀强电场的电场线是间隔相等、彼此平行的直线。
