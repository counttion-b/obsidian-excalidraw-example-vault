
# 静力学1-力的基本概念与性质 #h0


# 力的基本概念与性质
1. 力是物质间的相互作用。物质包括实物粒子和场。
2. 四大基本作用力
	1. 万有引力:重力就是由于万有引力产生的.
	2. 电磁相互作用:生活中所涉及的绝大多数力都是电磁力. 例如弹力, 摩擦力, 分子间的引力和斥力. 这些里本质上都是电磁力.
	3. 强相互作用: 强相互作用发生在原子核内部.由于强相互作用，质子和中子能够被束缚在一起，形成稳定的原子核.
	4. 弱相互作用.弱相互作用是在原子核的 $\beta$ 衰变中发现的.
3. 以一对质子相距 $10^{-16}\text{m}$ 时，假定强相互作用强度为 1：电磁相互作用为 $10^{-2}$;弱相互作用为 $10^{-12}$; 引力相互作用为 $10^{-40}$.
## 1. 力的性质
### 1.1. 物质性
主要对象：质点，点电荷，连接体，流体——受力物体，应用原理的对象；
辅助对象：面，轻绳，轻杆，轻弹簧，轻滑轮，场，理想气体——施力物体，各自有不同性质；
### 1.2. 瞬时性
力可以瞬时突变(弹簧弹力瞬间不突变).

用且仅用牛顿定律 $F=ma$ 求瞬时受力问题. 使用 $F=ma$ 时,只需考虑这一个瞬间的状态.
力在一个过程中的积累, 分为空间积累和时间积累, 对应了动能定理 $W_合=\Delta E_k$ 和动量定理 $I_合=\Delta p$. 同时可以定义平均力的概念, $\bar{F(x)}=\frac{\Delta E_k}{\Delta x}$ 和 $\bar{F(t)}=\frac{\Delta p}{\Delta t}$. 所以从本质上来说, 高中物理最核心的方法只有一个 $F=ma$ !

### 1.4. 矢量性
矢量求解方法：
1. 计算法：规定正方向, 列式计算. 只能在一条直线上计算, **一维**.
2. 图解法：平行四边形/三角形, 平面内**二维**计算.
力的合成与分解.
	物理思想：等效替代
	合力范围： 
两个力大小均为 $F$ ，夹角 $120^{\circ}$ ，合力大小为 $\_\_\_\_$ ．
三个力大小均为 $F$ ，夹角 $120^{\circ}$ ，合力大小为 $\_\_\_\_$  ．
在处理三个力及以下的问题时, **推荐使用图解, 即三角形法**. 可以利用三角函数关系求解各边, 也更直观的看到矢量的动态变化.

## 2. 力的分类与效果
### 2.1. 力的分类
1. 性质：弹力，摩擦力等
2. 效果：向心力，回复力，合力.
3. 对象：内力，外力
4. 作用方式：接触力，场力
5. 做功特点：保守力，非保守力
6.  判断方法: 主动力, 被动力

### 2.2. 力的效果
静力学效果：产生形变
动力学效果：产生加速度（改变物体运动状态）
