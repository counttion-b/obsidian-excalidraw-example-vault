# 碰撞的分类
1．弹性碰撞：在弹性碰撞过程中，系统的动量和机械能同时守恒。这意味着在碰撞前后，参与碰撞的物体组成的系统，其总动量保持不变，总机械能（包括动能和势能）也保持不变。

2．非弹性碰撞：如果碰撞过程中，系统的总动量守恒，但机械能不守恒。这样的碰撞称为非弹性碰撞。

3．一维碰撞：两个物体碰撞前后的运动方向都在同一条直线上。可以简单理解为物体只沿着一个方向（比如水平方向或者竖直方向）发生碰撞。

如：在光滑水平轨道上，两个滑块的碰撞。假设滑块 A 以一定速度向静止的滑块 B 运动，碰撞后两个滑块依然在这条轨道上运动，它们的运动方向没有改变，始终在轨道的直线方向上，这就是典型的一维碰撞。

4．二维碰撞：两个物体碰撞前后的运动方向不在同一条直线上，涉及到平面内两个方向的速度变化。

如：台球桌上，母球以一定角度撞击目标球。母球的运动方向和目标球碰撞后的运动方向不在同一条直线上，而是分布在台球桌这个平面内，这种碰撞就属于二维碰撞。

# 非弹性碰撞
1．一般非弹性碰撞：一般非弹性碰撞的过程中，碰后系统总动能小于碰前系统总动能，系统动量仍然守恒。

动量守恒：$m_1 v_1+m_2 v_2=m_1 v_1{ }^{\prime}+m_1 v_2{ }^{\prime}$


动能有损失：$\frac{1}{2} m_1 v_1^2+\frac{1}{2} m_2 v_2^2=\frac{1}{2}\left(m_1+m_2\right) v_0^2+\Delta \mathrm{E}$


前后的速度差不等，$v_1-v_2>v_2^{\prime}-v_1^{\prime}$ ，但符合 $\left(v_1-v_2\right) e=v_2^{\prime}-v_1^{\prime}$


其中 $e=\frac{v_2^{\prime}-v_1^{\prime}}{v_1-v_2}$ ，称之为恢复系数，恢复系数与材质等诸多因素有关。

2．完全非弹性碰撞：当碰撞之后速度 $v_1{ }^{\prime}=v_2{ }^{\prime}=v_{\text {共时，即两物体共速，系统损失的动能最大，称为完全 }}$非弹性碰撞。


动量守恒：$m_1 v_1+m_2 v_2=\left(m_1+m_2\right) v$

动能损失最大：$\frac{1}{2} m_1 v_1^2+\frac{1}{2} m_2 v_2^2=\frac{1}{2}\left(m_1+m_2\right) v_0^2+\Delta \mathrm{E}_{\text {max }}$

碰撞后速度：$v=\frac{m_1 v_1+m_2 v_2}{m_1+m_2}$ ；

注意：＂粘在—起＂＂碰后共速＂等关键词均描述完全非弹性碰撞。

# 碰撞合理性判断
1．动量守恒：

（1）原理：在一个孤立系统中，系统不受外力或所受外力的合力为零，那么系统的总动量保持不变。

（2）判断方法：计算碰撞前系统的总动量和碰撞后系统的总动量，若两者相等，则满足动量守恒定律，碰撞在动量方面是合理的。

2．能量不增：

（1）原理：碰撞过程中，系统的总机械能不会增加，只会减少或保持不变。这是因为在实际碰撞中，往往会有一部分机械能转化为其他形式的能量，如热能、声能等。

（2）判断方法：分别计算碰撞前系统的总机械能和碰撞后系统的总机械能，若碰撞后总机械能小于或等于碰撞前总机械能，则满足能量不增原则，碰撞在能量方面是合理的。

3．碰后不穿：

（1）原理：碰撞后两个物体的位置关系要符合实际情况，即一个物体不能穿过另一个物体。

（2）判断方法：根据碰撞后物体的速度和位置信息，判断它们是否会在空间上出现相互穿透的情况。如果碰撞后两物体的位置和运动状态使得它们不会相互穿透，则满足碰后不穿的条件，碰撞是合理的。

4．瞬间完成：

（1）原理：碰撞过程相对于物体的整体运动过程来说是非常短暂的，在这个极短的时间内，物体间的相互作用发生并结束，之后物体各自以新的状态继续运动。

（2）判断方法：如果在分析问题时，碰撞前后物体的状态变化是在一个可以忽略不计的短时间内完成的，那么就可以认为碰撞是瞬间完成的，符合实际情况，是合理的。
