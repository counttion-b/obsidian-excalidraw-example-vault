# 正功与负功的判断
1．若力与物体位移（瞬时速度）夹角为锐角，则该力对物体做正功，使物体的动能增加。

2．若力与物体位移（瞬时速度）夹角为钝角，则该力对物体做负功，使物体的动能减少。

3．若力与物体位移（瞬时速度）夹角为直角，则该力对物体不做功。
# 做功的计算
1．功的计算：力对物体所做的功，等于力的大小、位移的大小、力与位移夹角的余弦值这三者的乘积，即：$W=F l \cos \alpha$ 。需注意该方法只适用于恒力做功。

2．总功的计算：

（1）可以先对物体进行受力分析，求出物体所受到的合外力，再找出物体某段过程中的位移，结合公式 $W_{\text {合 }}=F_{\text {合 }} x \cos \theta$ ，即可求这段过程中的总功。

（2）也可以先求出各个分力做的功，然后再代数求和，最终算出总功，即：


$$
W_{\text {合 }}=W_1+W_2+W_3+\ldots \ldots \text { 。 }
$$
# 变力做功
若作用在物体上的某个力 $F$ 大小不变，方向改变，但其方向与物体瞬时速度 $v$ 的方向始终共线，则该力 $F$ 在某段过程中对物体做功的计算公式为：$W=F s$ ，其中 $s$ 为这段过程中物体运动的路程。若 $F$ 与 $v$ 始终同向，则做正功，若 $F$ 与 $v$ 始终反向，则做负功。

比如我们寒假讲过的滑动摩擦力的做功公式：$W=f s$ ，就是用过上述方法推导的。

# 功率
1．平均功率：表示在一段时间中力做功的平均快慢程度，即 $\bar{P}=\frac{W}{t}$ 。

2．瞬时功率：表示力在某一瞬间做功的快慢程度，即 $P=\frac{W}{\Delta t}=\frac{F \Delta x \cos \theta}{\Delta t}=F v \cos \theta$（式中 $v$ 是瞬时速度， $\cos \theta$ 是力与速度的夹角的余弦值）。
